# 演示图清单

这里放 README 用到的演示图，**把截图按文件名覆盖进来就行**（建议 1440×810，16:9，单张 < 1MB）。

缺图时可以重新生成占位：`node scripts/make-demo-placeholders.mjs`（已存在的图不会被覆盖）。

| 文件 | 该拍什么 | 怎么拍 |
| --- | --- | --- |
| `01-qq-panel.png` | QQ 交互面板：解析完成的卡片 + 清晰度 / 视频 / 弹幕 / 大小 表格 + 一排按钮 | 群里发链接后机器人回的第一条消息 |
| `02-bilibili-info.png` | B站视频信息卡（封面、UP 主、数据栏、热门弹幕） | 解析一个 B站视频后的卡片 |
| `03-comment-card.png` | 评论区长图：超过 20MB 或发送失败时自动切片，再用一条 markdown 拼回一整张 | 评论区卡片的完整长图 |
| `04-douyin-gallery.png` | 抖音图集：多张图合成一条 markdown 发送，实况视频跟在后面 | 解析抖音图集后的消息 |
| `05-xiaohongshu-note.png` | 小红书笔记卡片 + 评论区 | 解析小红书笔记后的面板 |
| `06-download-progress.png` | 下载进度提示：正在获取下载链接 / 正在合并音轨 / 发送中… | 点完画质按钮后的进度消息 |
| `07-webui-qq-tab.png` | 配置面板 /kkk 的「QQ 适配器」分类（控制台里的「kkk 配置」页就是它） | 浏览器打开 /kkk 并切到 QQ 适配器标签 |
| `08-console-entry.png` | Koishi 控制台：侧边栏入口 + 插件配置里的「QQ 适配器」与折叠的「Koishi 原生设置」 | 控制台插件配置页 |
| `09-error-card.png` | 错误诊断卡片：框架版本 / 插件版本 / 适配器，以及 QQ 群号与仓库地址 | 触发一次报错的卡片 |
